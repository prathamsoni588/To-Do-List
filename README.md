# 📝 To-Do List with Local Storage

A modern and responsive **To-Do List web application** built using **HTML, CSS, and Vanilla JavaScript**. It helps users organize daily tasks, manage time slots, and track productivity.

## ✨ Features

* ➕ Add new tasks
* ⏰ Set start and end time for each task
* ✅ Mark tasks as completed
* 🗑️ Delete individual tasks
* 📊 View Total, Completed, and Remaining tasks
* 🧹 Clear all completed tasks
* 💾 Automatically save tasks using Local Storage
* 🔄 Tasks remain after refreshing the page
* 📱 Fully responsive design
* 🎨 Clean and modern user interface
* ♿ Simple and accessible interface

## 🛠️ Technologies Used

* **HTML5** – Page structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and DOM manipulation
* **Local Storage** – Saving tasks in the browser

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start adding your tasks.

No installation or external libraries are required.

## 📸 How It Works

Add a task such as:

```text
Study DBMS
5:00 AM → 6:00 AM
```

You can then mark it as completed or delete it. Your tasks are automatically stored in the browser using **Local Storage**.

## 🎯 Purpose

This project was created to practice front-end web development concepts such as DOM manipulation, event handling, form validation, responsive CSS, JavaScript arrays and objects, and browser Local Storage.
